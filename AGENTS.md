# Instructions for AI coding assistants

This repository is a skill. To redesign a contractor's website, read `SKILL.md` in this folder and follow it exactly for the URL the user gives you. Paths in `SKILL.md` are relative to this folder.

Ground rules (details in `SKILL.md`):
- Never invent business facts, prices, licences or reviews. Flag unknowns for the user to confirm.
- Never commit or print secrets. API keys go only in the generated project's gitignored `.env`.
- Carry over 100% of the original text and meet the content floors in `scripts/floors.json`; the scripts verify both.
- Do not deploy or publish anything unless the user asks.
